# CI/CD Pipeline Failure Prediction & Optimization Platform

## Project Goal

Build a platform that collects CI/CD pipeline execution data,
predicts pipeline failures using machine learning, identifies
pipeline bottlenecks, and provides optimization recommendations.

## Technology Stack

- Frontend: React
- Backend: Python + FastAPI
- Database: PostgreSQL
- Machine Learning: pandas + scikit-learn
- CI/CD: GitHub Actions
- Containerization: Docker
- Version Control: Git + GitHub

## Development Rules

1. Keep the project modular.
2. Do not modify another member's module without discussion.
3. Never commit API tokens, passwords, or other secrets.
4. Use environment variables for secrets.
5. Write tests for important functionality.
6. Use clear variable and function names.
7. Keep APIs documented.
8. Do not add unnecessary technologies.
9. Test features locally before committing.
10. Do not directly push feature work to the main branch.
